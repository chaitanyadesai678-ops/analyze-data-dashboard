# Analyze the Data

## Project Description
A data analysis dashboard built using Python,
Pandas, Streamlit, and Matplotlib.

## Features
- CSV dataset upload
- Dataset preview
- Rows and columns overview
- Duplicate and missing value analysis
- Statistical summary
- Histogram visualization
- CSV download

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run the application:
   streamlit run analyze_data.py
